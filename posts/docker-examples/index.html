Docker Examples

Updated: 2025-05-28 |  at  07:30 AM

자주 사용하는 Docker Example을 소개한다.

Docker-Compose 를 사용하는게 가장 관리하기가 좋다. 특히 Volumes를 잘 활용하면 Container를 삭제후 재실행해도 주요파일 들이 유지돼서 좋다.

Docker를 사용하면 복잡한 환경설정이 심플해진다. 복잡한 환경설정은 Dockerfile에서 관리하고 본 서비스에 집중 할 수 있다.

간단한 서비스라면 Docker를 사용하지 않는 것도 괜찮다고 생각한다.

각각의 Docker는 서비스별로 별도 폴더를 만들어서 운영하는게 좋다. 아래는 가장 자주 사용되는 몇가지 예시들을 모아놓았다.

Nginx

nginx는 고성능 웹서버다 아래는 공식홈페이지 설명이다.

https://nginx.org/

nginx ("engine x") is an HTTP web server, reverse proxy, content cache, load balancer,
TCP/UDP proxy server, and mail proxy server.
Originally written by Igor Sysoev and distributed under the 2-clause BSD License.
Enterprise distributions, commercial support and training are available from F5, Inc.

아래는 Nginx 샘플이다. Step3에서 나만의 환경에 따라 작성하면 된다. Nginx 자체가 가벼워서 Docker를 이용해 운영하면 더 관리하기 좋다.

Dockerfile

#Step:1 Ubuntu (base image)
FROM ubuntu:latest

#Step:2 Nginx install
RUN apt-get update
RUN apt-get install -y -q nginx

#Step:3 file copy
COPY ./index.html /usr/share/nginx/html/

EXPOSE 80

#step:4 Nginx start
CMD ["nginx", "-g", "daemon off"]

아래는 index.html 샘플이다.

<h1>Hello, world from Docker!</h1>

Postgresql

Postgresql은 가장 인기있는 오픈소스 데이타베이스이다. 아래는 공식홈페이지 설명이다.

https://www.postgresql.org/

PostgreSQL: The World's Most Advanced Open Source Relational Database

아래는 Postgresql 샘플이다. 특별히 작업할게 없으므로 docker-compose로 바로 작업한다. POSTGRES_DB에 원하는 데이타베이스 카탈로그명을 사용한다. volumes를 통해 현재 운영환경의 폴더(./data)를 Postgres의 데이타베이스 저장소로 매핑하면 Container를 삭제후 재생성해도 데이타는 유지돼서 편리하다. DB 버전은 운영환경에 맞게 수정한다.

docker-compose.yaml

services:
  postgres:
    container_name: postgres
    image: postgres:16
    restart: always
    ports:
      - 5432:5432
    volumes:
      - ./data:/var/lib/postgresql/data
    environment:
      - POSTGRES_USER=postgres
      - POSTGRES_PASSWORD=00000000
      - POSTGRES_DB=postgres

WordPress

WordPress는 플러그인과 테마가 잘 갖춰진 퍼블리싱 플랫폼이다. 설치형 블로그 혹은 CMS (Contents Management System)

아래는 공식 홈페이지 소개이다. https://ko.wordpress.org/

워드프레스를 만나보세요

크리에이터와 소규모 비즈니스부터 대기업에 이르기까지 전 세계 수백만 웹사이트가 선택한 오픈 소스 퍼블리싱 플랫폼입니다.

아래는 wordPress 환경 구성이다. Mysql 5.7을 사용하는 버전으로 WordPress 학습용도로 생각해야한다. 최신버전은 환경 및 버전에 따라 세부 정보를 업데이트하여 사용해야한다.

docker-compose.yaml

services:
  db:
    image: mysql:5.7
    volumes:
      - ./mysql:/var/lib/mysql
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: wordpress
      MYSQL_DATABASE: wordpress
      MYSQL_USER: wordpress
      MYSQL_PASSWORD: wordpress
  wordpress:
    image: wordpress:latest
    volumes:
      - ./wp:/var/www/html
    ports:
      - "8000:80"
    restart: always
    environment:
      WORDPRESS_DB_HOST: db:3306
      WORDPRESS_DB_PASSWORD: wordpress

Docker에 대한 자세한 정보는 아래 경로에서 학습 가능하다. DockerDocs
